Selected work

Embedded calibration storage and drift correction for an uncooled microbolometer

IDEAS, Oslo · 2026

Uncooled microbolometer arrays self-heat, so their output drifts. I addressed this on one camera through two separate methods.

  • Drift correction. With no temperature sensor on the focal plane, I modelled per-row drift as an exponential in warm-up time and corrected it offline on the host.
  • Calibration storage, in firmware. On the Zynq-7000 I brought up the on-module eMMC, wrote an FTP service, and built a temperature-indexed lookup table that applies a per-pixel calibration inside the camera, independent of the host.
  • Embedded C
  • Zynq-7000
  • Vivado & Vitis
  • FreeRTOS / LwIP
  • Jupyter

Real-time control software for a thermal imaging system

IDEAS, Oslo · 2025–2026

Developed a Qt desktop application for a 640×480 LWIR thermal camera, streaming 16-bit video over RTP/UDP into a GLSL display shader, with the tooling an operator needs to use the image: auto-range contrast, custom charts, per-frame statistics, pixel profiling and playback through the live pipeline.

Throughput then topped out at 12 FPS. Boost for data processing plus QtGraph for GPU-accelerated charts went the wrong way — 6 FPS, with unstable charts and histogram. SSE4.1 SIMD intrinsics on the per-frame processing brought it to a stable 45 FPS in loopback testing.

  • C++ / Qt 6
  • GLSL
  • SSE4.1 SIMD
  • FFmpeg
  • RTP / UDP

IoT and ML-based motor monitoring device

3CsLab, HUST · 2023

A device that clamps onto a motor housing, watches its parameters, and flags abnormal behaviour through a classification model, alerting a phone app. I led a team of five and did the schematic and PCB layout in Altium, then took the board through four revisions - hand-soldered and bench-tested each one - with a 3D-printed enclosure designed in SolidWorks. Detection accuracy came out above 95%.

  • Altium Designer
  • PCB design
  • ESP32
  • SolidWorks

Smart gate system

3CsLab, HUST · 2022

An IoT gate that opens on face detection or an RFID card, with an admin web page that manages and visualises every tag. I led a team of three, built the local web server and database, and designed a separate ESP32-based reader for enrolling new cards.
